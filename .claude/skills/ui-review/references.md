# 参考アプリ（厳選リスト）

/ui-review が修正案を作るときに最優先で参照する、実在アプリの一覧。
初回の /ui-review 実行時に候補が提示され、選んだものがここに追記される。手で追加・削除してもよい。

## 書式

```
## <アプリ名>
- URL: <...>
- 参考にする画面: <画面名やURL>
- 参考にする点: <何をどう処理しているか。1〜3行>
- 追加日: YYYY-MM-DD
```

## マネーフォワード ME

- URL: https://support.me.moneyforward.com/hc/ja/articles/4406628781977 （ヘルプ「『家計簿』画面大解剖！！」）、https://support.me.moneyforward.com/hc/ja/articles/24226189541401 （ヘルプ「『ホーム画面』の見方について」）
- 参考にする画面: ホームの「今月の家計簿」、家計簿タブ
- 参考にする点: グラフの上の先頭に「収支（収入 − 支出）」を置き、マイナスなら赤字と分かるようにしている。振替や「計算対象 OFF」の取引は集計に含めない。いちばん見たい1行（差額）を先頭に、詳しい内訳を後ろに回す配置の参考になる。（公式ヘルプは WebFetch で開けず、検索結果の抜粋で確認）
- 追加日: 2026-10-11

## Moneytree（マネーツリー）

- URL: https://getmoneytree.com/jp/app/about 、https://help.getmoneytree.com/ja/articles/8185062
- 参考にする画面: 口座残高画面
- 参考にする点: いちばん上に「全資産」の合計を置き、その下を「銀行口座」「証券」などの種類のセクションに分けて、セクションごとに小計を出す。口座別残高を種類で分けるか、合計をどこに置くかを決めるときの参考になる。（公式ヘルプは WebFetch で開けず、検索結果の抜粋で確認）
- 追加日: 2026-10-11

## Apple ウォレット（Apple Card の支出サマリー）

- URL: https://support.apple.com/en-us/102329
- 参考にする画面: Apple Card の「Monthly Activity」支出サマリー
- 参考にする点: 期間を週・月・年で切り替える。「Total Spending」の合計額の直下に、前の期間より多いか少ないかを短い一文で添える。月の出費の主数字のすぐ下に比較を一文で置く見せ方の参考になる。
- 追加日: 2026-10-11
