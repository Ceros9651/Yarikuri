# Proposal

## Why

スマホでは、過去の取引を取引一覧で日付順にたどることはほとんどなく、ホームの「カテゴリ別の出費」から見ることが多い（PBI-36）。それなのに下部タブの「取引一覧」は絞り込みのない取引の一覧を開き、ホームはカテゴリ別の出費が月の収支のすぐ下を占めていて、カードの利用額や残高を見るにはスクロールが要る。スマホのタブの役割を使い方に合わせ、カテゴリ別の出費はタブで、ホームは収支・カード・残高・予算で見られるようにする。

## What Changes

いずれもスマホ版（画面幅 1024px 未満）だけの変更で、PC 版（1024px 以上）のホーム・取引一覧・サイドバーは変えない。

- 下部タブの「取引一覧」を「出費」に改名する（URL は `/transactions` のまま、アイコンは変えない）。
- 「出費」タブを絞り込みなしで開くと、取引の一覧ではなく、選択中の月のカテゴリ別の出費（金額の大きい順、金額・割合・バー）を表示する。見出しの行に月の出費の合計を出し、月の切り替えを置く。
- カテゴリの行をタップすると、今と同じくそのカテゴリで絞り込んだ取引の一覧を開き、そこから取引を編集できる。戻る操作でカテゴリ別の出費に戻る。
- カテゴリ別の出費の下に「すべての取引」への導線を置き、収入・振替・残高調整を含む月の全取引の一覧も開けるようにする（スマホで収入などを編集する手段を残すため）。一覧の表示中に絞り込みを「すべて」に戻しても、一覧のまま表示する。
- ホームから「カテゴリ別の出費」をなくし、上から「月の収支（差額）」「カード別の利用額」「残高」「予算」の順に並べる（予算と残高の順を入れ替える）。
- 画面幅を 1024px 境界をまたいで変えると、その場でスマホ版・PC 版の表示に切り替わる。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `monthly-summary`: スマホ版のホームのセクションの並び（カテゴリ別の出費を除き、残高を予算の上へ）と、カテゴリ別の出費を表示する場所（スマホ版は「出費」タブ、PC 版はホーム）を改める。
- `transactions`: スマホ版の「出費」タブを絞り込みなしで開いたときにカテゴリ別の出費を表示する要件と、そこから絞り込んだ一覧・全取引の一覧を開く要件を加え、「タブからは絞り込みなしの一覧を開く」をスマホ版では改める。
- `pwa-app`: 下部ナビゲーションのタブ名を「ホーム／出費／入力／設定」に改め、PC 版がスマホ版と同じ画面・データを表示するという要件に、ホームと取引一覧の例外を加える。

## Impact

- `src/hooks/`: 画面幅が PC 版かどうかを `matchMedia('(min-width: 1024px)')` で返すフックを加える（幅の変更に追従）。
- `src/components/`: ホームのカテゴリ別の出費を部品に切り出し、ホーム（PC 版）と取引一覧（スマホ版）で共用する。
- `src/pages/HomePage.tsx`: スマホ版ではカテゴリ別の出費を出さず、右列の残高と予算の順を入れ替える。PC 版の表示と読み上げの順は保つ。
- `src/pages/TransactionsPage.tsx`: スマホ版で絞り込みがないときにカテゴリ別の出費を表示し、URL の `view=list` で全取引の一覧を表示する。
- `src/components/Layout.tsx`: スマホ版の下部タブの名前を「出費」にする（PC 版のサイドバーは「取引一覧」）。
- テスト: jsdom に `matchMedia` がないため、画面幅を切り替えるテスト用のヘルパーを加え、ホーム・取引一覧・レイアウトのテストにスマホ版のケースを足す。
- `docs/design-principles.md`: スマホ版のホームの並びと「出費」タブのルールを追記する。
- 依存ライブラリの追加はない。データ、同期、バックアップには影響しない。
- 注意: ブランチ `PBI-36` は `origin/dev` より古い（PBI-3 のカレンダー等が入っていない）。この計画は `origin/dev` のコードと spec を前提にしているため、実装の前に `origin/dev` を取り込む。
