# Design

## 方針

`/ui-review ホーム` で採用した5つの案を実装する。どれも「装飾を剥がす」ことが目的ではなく、毎日開いて最初に確かめたいもの（今月の差額、残高の合計、予算の注意）が先に・大きく目に入るように、情報の重みと配置を合わせることが目的。

共通クラス（`.card` / `.list` / `button` / `input`）と `:root` の `--radius` は変えない。ホームの見た目はホーム専用のクラスで作り、取引一覧や設定の見た目は変えない。

## 他画面への影響

| 変更                            | ホーム | 取引一覧 | 取引の編集 | 入力 | 設定 |
| ------------------------------- | ------ | -------- | ---------- | ---- | ---- |
| 差額を主数字にした月の収支      | 変わる | なし     | なし       | なし | なし |
| セクションの箱をやめる          | 変わる | なし     | なし       | なし | なし |
| 合計を見出しの行へ、h1 を隠す   | 変わる | なし     | なし       | なし | なし |
| タブバーの絵文字を単色 svg へ   | 変わる | 変わる   | 変わる     | 変わる | 変わる |
| バーを無彩色、`--bar` を廃止    | 変わる | なし     | なし       | なし | なし |

- タブバー（`Layout.tsx`）は全画面共通なので、アイコンの形と色はすべての画面で変わる。タブの並び、文字ラベル、タップ領域（高さ 60px）、選択中の文字色は変わらない。
- `.bar-fill` と `--bar` を使っているのはホームだけ（`HomePage.tsx`）。`--warning` と `--danger` の値は変えないので、入力の保存直後に出る予算のお知らせ（`.notice.budget-alert`）の色は変わらない。
- 見出し「ホーム」を隠すのはホームだけ。取引一覧・入力・設定の h1 は表示したまま残す（他画面の h1 の扱いは次回以降のレビューで決める）。

## 決めたこと

- **合計の位置**: レビューで指摘されたのは残高の合計だが、採用した方針ルール「合計や結論の数字はセクション見出しと同じ行に置く」に合わせて、カード別の利用額の合計も同じ形にする。同じ画面の中で合計の位置が2通りあると、かえって読み方が揃わないため。
- **アイコンの作り方**: アイコンライブラリは入れず、4つの svg（ホーム／取引一覧／入力／設定）を手書きする。`width/height=24`、`fill="none"`、`stroke="currentColor"`、`stroke-width="1.75"`、`aria-hidden="true"`。色は親の `.tab` と `.tab.active` の `color` に任せる。
- **読み上げ専用のクラス**: 今のコードベースに無いので、`.visually-hidden`（`position:absolute; width:1px; height:1px; overflow:hidden; clip-path:inset(50%); white-space:nowrap`）を `index.css` に1つ追加する。
- **差額の色**: マイナスのときだけ `.expense`。プラスのときは通常の文字色（`--income` の緑にはしない。緑は収入の金額と選択状態に限る）。

## 採らなかった案

- **月の収支を「出費」中心にする（Apple ウォレット型）**: 振替や収入を含めた「今月いくら余っているか」が見たいので、差額を主にした。
- **3列のまま枠と中央寄せだけ外す**: 3つの金額が同じ重さのままで、結論が分からない問題が残る。
- **`.card` の角丸と余白を全画面で小さくする**: 取引一覧・設定まで変わり、`input` / `button` の 8px とも揃わなくなる。設定のフォームのように箱で独立させたい画面もあるので、ホームだけ箱をやめた。
- **予算の「注意」を画面上部に1行でまとめる（YNAB 型）**: 既存の spec「ホームでの超過のまとめ表示」（超過がないときは表示しない）の変更が必要になる。今回はレイアウトの圧縮で予算を上に寄せることを優先した。
- **選択中だけ塗りつぶしのアイコン**: アイコンを8つ用意する必要があり、色の変化だけで選択状態は十分に分かると判断した。
- **出費のバーを出費色の淡い版にし、`--warning` を黄寄りにする**: `--warning` を変えると全画面の予算のお知らせに波及する。色の意味を「対応が必要な状態」に絞るほうが単純。
