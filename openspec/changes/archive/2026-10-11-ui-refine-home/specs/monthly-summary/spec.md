# Spec Delta

## ADDED Requirements

### Requirement: 差額を主数字として表示する
ホーム画面は選択中の月の差額を、収入・出費より大きい文字で、月の収支の先頭に左揃えで表示しなければならない（SHALL）。差額がマイナスのときは出費と同じ色で表示しなければならない（SHALL）。収入・出費は差額の下に、ラベルを左、金額を右にそろえて表示する。収支の金額は、幅 360px の画面で7桁になっても途中で改行してはならない（MUST NOT）。

#### Scenario: 差額がいちばん大きく表示される
- **WHEN** ユーザーがスマホで、収入 268,000 円・出費 35,030 円の月のホーム画面を開く
- **THEN** 差額「¥232,970」が収支の先頭に、収入・出費より大きい文字で左揃えに表示される
- **AND** その下に「収入 ¥268,000」「出費 ¥35,030」が、ラベル左・金額右で表示される

#### Scenario: マイナスの差額を出費の色で表示する
- **WHEN** ユーザーが幅 360px のスマホで、収入 100,000 円・出費 1,250,000 円の月のホーム画面を開く
- **THEN** 差額「-¥1,150,000」が出費と同じ色で、1行に収まって表示される

### Requirement: ホームのセクションを箱で囲まない
ホーム画面の各セクション（残高・カテゴリ別の出費・予算・カード別の利用額）は、枠線と角丸のある箱で囲まずに、見出しと罫線で区切った一覧として表示しなければならない（SHALL）。セクションどうしの間隔は、セクション内の行の間隔より大きくしなければならない（SHALL）。

#### Scenario: セクションが箱で囲まれていない
- **WHEN** ユーザーがスマホでホーム画面を開く
- **THEN** 残高・カテゴリ別の出費・予算・カード別の利用額の各セクションに、枠線と角丸の箱が表示されない
- **AND** 各セクションの行は1本の罫線で区切られ、セクションとセクションの間は行と行の間より広く空いている

### Requirement: 合計をセクション見出しの行に表示する
ホーム画面は、口座残高の合計を「残高」の見出しと同じ行の右側に、クレジットカードの利用額の合計を「カード別の利用額」の見出しと同じ行の右側に表示しなければならない（SHALL）。一覧の末尾に合計の行を重ねて表示してはならない（MUST NOT）。画面のレベル1見出し「ホーム」は、画面には表示せず、読み上げ（スクリーンリーダー）では読まれるように残さなければならない（SHALL）。

#### Scenario: 残高の合計が口座一覧より上に見える
- **WHEN** ユーザーが 390×844 のスマホでホーム画面を開く
- **THEN** 残高の合計が「残高」の見出しの行に表示され、スクロールせずに見える
- **AND** 口座一覧の末尾には「合計」の行が表示されない

#### Scenario: 見出し「ホーム」は読み上げだけに残る
- **WHEN** ユーザーがスマホでホーム画面を開く
- **THEN** 画面の最上部に「ホーム」の見出しは表示されず、月の切り替えが最初に表示される
- **AND** スクリーンリーダーではレベル1見出し「ホーム」が読み上げられる

### Requirement: カテゴリ別の出費のバーに収入の色を使わない
ホーム画面のカテゴリ別の出費のバーは、収入やアクセントの緑を使わず、無彩色で表示しなければならない（SHALL）。

#### Scenario: 出費の内訳のバーが無彩色で表示される
- **WHEN** ユーザーがスマホで、出費のある月のホーム画面を開く
- **THEN** カテゴリ別の出費の各バーは灰色系で表示され、収入の金額と同じ緑では表示されない
