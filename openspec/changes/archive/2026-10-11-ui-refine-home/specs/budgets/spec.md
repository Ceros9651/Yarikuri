# Spec Delta

## ADDED Requirements

### Requirement: 予算をカテゴリ別の出費より上に表示する
ホーム画面は予算の消化状況を、口座別残高の後、カテゴリ別の出費より上に表示しなければならない（SHALL）。

#### Scenario: 予算の見出しがスクロールせずに見える
- **WHEN** ユーザーが 390×844 のスマホで、口座が3件ある月のホーム画面を開く
- **THEN** 予算の見出しがスクロールせずに見え、カテゴリ別の出費はその下に表示される

### Requirement: 予算のバーは注意と超過だけに色を付ける
ホーム画面の予算の消化状況のバーは、状態が通常のカテゴリでは無彩色で表示し、注意のカテゴリは警告の色、超過のカテゴリは危険の色で表示しなければならない（SHALL）。通常のカテゴリのバーに、収入やアクセントの緑を使ってはならない（MUST NOT）。

#### Scenario: 色付きのバーは注意と超過だけになる
- **WHEN** ユーザーがスマホで、予算の状態が通常・注意・超過のカテゴリがそれぞれある月のホーム画面を開く
- **THEN** 通常のカテゴリのバーは灰色系で表示される
- **AND** 注意のカテゴリのバーは警告の色、超過のカテゴリのバーは危険の色で表示される
