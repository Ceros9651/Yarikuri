# Spec Delta

## ADDED Requirements

### Requirement: 下部ナビゲーションのアイコンは単色で選択状態を示す
下部ナビゲーションの各タブは、アプリの文字色に従う単色のアイコンと文字ラベルを持たなければならない（SHALL）。アイコンに OS ごとに見た目の変わる絵文字を使ってはならない（MUST NOT）。選択中のタブは、アイコンと文字の両方をアクセント色で示さなければならない（SHALL）。アイコンは読み上げの対象にせず、タブの名前は文字ラベルで読み上げられなければならない（SHALL）。

#### Scenario: 選択中のタブだけアイコンと文字が緑になる
- **WHEN** ユーザーがスマホで取引一覧タブを開く
- **THEN** 「取引一覧」タブのアイコンと文字がアクセント色（緑）で表示される
- **AND** ホーム・入力・設定のタブのアイコンと文字は、選択されていない色（灰色系）で表示される

#### Scenario: ダークモードでもアイコンが配色に合う
- **WHEN** ユーザーが端末をダークモードにしてアプリを開く
- **THEN** タブのアイコンはダークモードの文字色とアクセント色で表示され、多色の絵文字は表示されない
