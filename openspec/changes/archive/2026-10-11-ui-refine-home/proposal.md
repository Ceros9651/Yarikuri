# Proposal

## Why

ホーム画面は毎日開いて「今月あといくら余っているか」「残高はいくらか」「予算は大丈夫か」を確かめる画面だが、今の見た目は生成AIが作りがちな画一的な構成になっていて、読む順番と情報の重みが合っていない（`/ui-review ホーム` の結果。スクショは `screenshots/before-*.png`）。

- 月の収支が「収入／出費／差額」の同じ大きさの3つの箱を中央寄せで並べただけで、結論の差額が目立たず、マイナスでも色が変わらない。金額が7桁になると「¥2,303,03 / 0」のように桁の途中で折れて読めない（`before-long-amount-mobile-sm.png`）。
- 収支・残高・カテゴリ・予算・カード利用という性質の違う情報が、すべて同じ12px角丸の枠付きカードで積まれていて、主と従の区別がない。箱の中でも罫線で行を区切っているので区切りが二重になり、外枠と余白だけで約170pxを使っている。
- 残高の合計は口座一覧の末尾にあり、予算はスクロールしないと見えない（390×844 で top=946px）。画面上部の見出し「ホーム」は、選択中のタブと同じことを繰り返して場所を取っている。
- 下部のタブバーのアイコンが OS 依存のカラー絵文字（🏠📋✏️⚙️）で、アプリの緑の配色と合わず、選択中のタブでもアイコンの色が変わらない。ダークモードでは絵文字だけが浮いて見える。
- カテゴリ別の出費のバーが、収入と同じ緑系の色で塗られている。予算の「注意」の茶橙は出費の金額の色とほぼ同じで、色を見ても意味が分からない。

## What Changes

- 月の収支は差額を主数字（最大の文字・左揃え、マイナスなら出費の色）にし、収入・出費はその下に「ラベル左／金額右」の行で添える。金額は折り返さない。参考: マネーフォワード ME のホーム「今月の家計簿」（先頭に収支を置き、マイナスなら赤字と分かる）。
- ホームの各セクション（残高・カテゴリ別の出費・予算・カード別の利用額）は枠と角丸の箱をやめ、見出し＋1pxの罫線リストで並べ、セクションどうしは余白で区切る。`.card` 自体は変えず、ホーム専用のクラスを作る。参考: Moneytree の口座残高画面（見出しと小計でセクションを区切る）。
- 残高とカード別利用額の合計を、一覧の末尾の「合計」行からセクション見出しの行の右側へ移す。見出し「ホーム」は画面には出さず、読み上げ用に残す。参考: Moneytree の口座残高画面（全資産の合計を一覧より上に置く）。
- タブバーの絵文字を、文字色に従う単色の線画アイコン（インライン svg、`currentColor`）に置き換え、選択中のタブはアイコンと文字の両方を緑にする。文字ラベルとタップ領域はそのまま。参考: iOS の App Store アプリの下部タブ（単色の記号＋文字、選択中だけアクセント色）。
- カテゴリ別の出費のバーと通常状態の予算のバーを無彩色にし、色を付けるのは予算の注意（`--warning`）と超過（`--danger`）だけにする。`--bar` トークンは廃止する。参考: YNAB（カテゴリの残額は対応が必要なときだけ色が付く）。
- （`/ui-review --verify` で追加）予算のセクションを、残高の直後・カテゴリ別の出費より上へ移す。上の変更だけでは予算の見出しが最初の画面に入らなかったため。あわせて、セクションの間の余白を広げ、カテゴリ別の出費のバーを薄い灰色にして、数字より目立たないようにする。
- データや操作（集計の値、月の切り替え、画面遷移、タブの並び）は変えない。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `monthly-summary`: 差額を主数字として表示すること、金額を折り返さないこと、ホームのセクションを箱で囲まないこと、残高とカード利用額の合計を見出しの行に置くこと、カテゴリ別のバーに収入の色を使わないことを要件として追加する。
- `budgets`: ホームの予算のバーで色を付けるのは注意・超過のカテゴリだけにすること、予算をカテゴリ別の出費より上に表示することを要件として追加する。
- `pwa-app`: 下部ナビゲーションのアイコンを単色にし、選択中のタブはアイコンと文字の両方をアクセント色で示すことを要件として追加する。

## Impact

- `src/pages/HomePage.tsx`: 月の収支の構造、各セクションのクラス、合計の位置、見出し「ホーム」の扱い。`data-testid`（`income` / `expense` / `net` / `balance-total` / `card-total`）は残す。
- `src/components/Layout.tsx`: タブのアイコンを絵文字から svg に置き換える。
- `src/index.css`: `.summary-grid` 系を差額中心の新しいクラスに置き換え、ホームのセクション用クラス・見出し行のクラス・読み上げ専用のクラスを追加する。`.tab-icon`、`.bar-fill` を変更し、`:root`（ライト・ダーク）から `--bar` を削除する。
- 影響する他画面: タブバーは全画面共通なので、取引一覧・取引の編集・入力・設定でもアイコンの見た目が変わる。`.card`・`.list`・`button` などの共通クラスと `--radius` は変えないので、それ以外の他画面への影響はない（詳細は design.md）。
- テスト: `src/components/Layout.test.tsx` はレベル1見出し「ホーム」とタブのリンク名に依存しているので、見出しを読み上げ用に残し、アイコンを `aria-hidden` にすれば変更不要。`src/pages/home.test.tsx` は残高とカード利用額の一覧の最後の行が「合計」であることを確かめていたので、合計を見出しの行へ移すのに合わせて、一覧の行数と内容の期待値を直す（合計の値は `data-testid` で引き続き確かめる）。
- 検証: jsdom ではレイアウトを計算しないため、`/ui-review --verify ui-refine-home` の Before/After スクショと実機で確認する。
- 参考スクショ: `screenshots/before-*.png`
