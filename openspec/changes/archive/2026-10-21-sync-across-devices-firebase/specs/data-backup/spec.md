# Spec Delta

## MODIFIED Requirements

### Requirement: JSON インポート
ユーザーはエクスポートした JSON ファイルを選択して、端末内の全データ（口座・カテゴリ・取引・予算）をファイルの内容で SHALL 置き換えられる。置き換えの前に、既存データが上書きされることを確認しなければならない（MUST）。サインインしている場合は、置き換えた内容を同期し、同じアカウントでサインインしている全端末のデータもファイルの内容に置き換わる。その場合の確認では、他の端末のデータも置き換わることを示さなければならない（MUST）。

#### Scenario: バックアップから復元する
- **WHEN** ユーザーがエクスポートしたファイルを選び、上書き確認で「置き換える」を選ぶ
- **THEN** 口座・カテゴリ・取引・予算がファイルの内容と同じになり、ホーム画面の集計と予算の消化状況もそれに基づいて表示される

#### Scenario: 上書き確認でキャンセルする
- **WHEN** ユーザーがファイルを選んだあと、上書き確認でキャンセルを選ぶ
- **THEN** 端末内のデータは変更されない

#### Scenario: 予算を含まない旧形式のファイルを読み込む
- **WHEN** ユーザーが予算機能の追加前にエクスポートしたファイルを選び、上書き確認で「置き換える」を選ぶ
- **THEN** 口座・カテゴリ・取引がファイルの内容と同じになり、予算は1つも設定されていない状態になる

#### Scenario: サインイン中にインポートする
- **WHEN** サインインしているスマホでファイルを選ぶ
- **THEN** 上書き確認に、同期している他の端末のデータも置き換わることが表示され、「置き換える」を選ぶと PC のデータもファイルの内容と同じになり、ファイルに含まれない取引は PC からも消える
