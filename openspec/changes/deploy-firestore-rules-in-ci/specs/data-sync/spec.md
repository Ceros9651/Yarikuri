# Spec Delta

## ADDED Requirements

### Requirement: 公開したアプリの記録はクラウドのルールで拒否されない
新しいバージョンのアプリを公開するときは、そのバージョンが読み書きするすべての種類の記録（口座・カテゴリ・取引・予算・月の開始日）を、本人のアカウントで読み書きできるクラウドのアクセスルールも SHALL 同時に反映する。ルールを反映できなかった場合、そのバージョンのアプリを公開してはならない（MUST NOT）。ルールの不足が原因で同期が止まっていた端末は、ルールが直ったあとアプリを開き直せば、サインインし直さなくても送れていなかった変更を送り、同期に戻らなければならない（MUST）。

#### Scenario: 新しい種類の記録を同期するバージョンを公開する
- **WHEN** 新しい種類の記録を同期するようにしたバージョンを公開し、その端末でサインインする
- **THEN** 新しい種類の記録も含めてクラウドに送られ、権限がないというエラーは表示されない

#### Scenario: 月の開始日を変えた端末でサインインする
- **WHEN** 月の開始日を1日以外に変えた端末で、Google アカウントでサインインする
- **THEN** 権限がないというエラーは出ず、月の開始日を含めて同期される

#### Scenario: ルールを反映できなかった
- **WHEN** 公開の途中でクラウドのアクセスルールの反映に失敗する
- **THEN** 新しいバージョンのアプリは公開されず、前のバージョンのまま使える

#### Scenario: ルールが直ったあと止まっていた端末が同期に戻る
- **WHEN** ルールの不足で「権限がありません」と表示されていた端末で、ルールが直ったあとアプリを開き直す
- **THEN** 送れていなかった変更がクラウドに送られ、エラーの表示が消えて同期済みの状態になる
