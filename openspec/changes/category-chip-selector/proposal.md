# Proposal

## Why

取引入力画面のカテゴリ選択は `<select>` ドロップダウンのため、1件入力するたびに「開くタップ」「選ぶタップ」の2タップと、画面外の選択肢へのスクロールが必要になる。出費カテゴリは9個程度と一覧できる数なので、チップ型のボタンを並べれば1タップで選べ、日々の入力が速くなる。

## What Changes

- 取引入力フォーム（収入・出費）のカテゴリ選択を `<select>` から、横並びのチップ型ボタン群に変更する。
- 各カテゴリは1タップで選択・切り替えでき、選択中のチップは視覚的に強調する（取引種類のセグメントボタンと同じ見た目の方向性）。
- チップが1行に収まらない場合は折り返して全カテゴリを常時表示する（スクロールや開閉を伴わない）。
- 口座選択（支払元・入金先・振替元・振替先）は現状の `<select>` のまま変更しない。

### Modified Capabilities
- `transactions`: 収入・出費の入力において、カテゴリの選択を1タップのチップ型UIで行えることを要件として追加する（既存の「収入の記録」「出費の記録」で指定する入力項目の指定方法を明確化）。

## Impact

- `src/components/TransactionForm.tsx`: カテゴリの `<select>` をチップ型ボタン群に置き換え。選択状態の管理（`categoryId` / `selectedCategory`）は現状のロジックを流用。
- `src/index.css`: チップ群のスタイル（折り返し・選択中の強調）を追加。
- アクセシビリティ: `role="radiogroup"` 相当のグルーピングと `aria-pressed` による選択状態の提示を維持する。
- データモデル・保存ロジック（`db/repository`、`domain/*`）への変更はなし。
