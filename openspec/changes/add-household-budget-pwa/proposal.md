# Proposal

## Why

日々の収入・出費と、財布（現金）・銀行口座・電子マネー・クレジットカードそれぞれの残高を、スマホからすぐ記録・確認できる手段がない。既存の家計簿アプリに頼らず、自分ひとり用の軽量な収支管理アプリを、サーバー運用コストなしでスマホのホーム画面から起動できる形（PWA）で用意する。

## What Changes

- React + Vite + TypeScript による新規 PWA「Yarikuri」を作成する（スマホのホーム画面に追加して全画面起動・オフライン動作）
- 口座管理：現金／銀行（複数）／電子マネーの口座を登録して初期残高を設定し、使わなくなった口座は非表示にできる
- クレジットカードを複数枚登録でき、カードを支払元とした出費をカードごとの利用額として記録・保持する。カードは残高・未払額・引き落とし口座を持たず、口座残高とは連携しない
- 取引入力：収入・出費（カテゴリ、金額、口座、日付、メモ）、口座間の振替（ATM引き出し・チャージ）、残高調整
- カテゴリ管理：収入・出費それぞれに初期カテゴリを用意し、追加・名前変更・非表示ができる
- 月次集計（暦月）：月の収入・出費・差額、口座別残高、出費のカテゴリ別内訳、クレカ別の月利用額。月の切り替えが可能
- 取引の一覧・編集・削除
- 全データの JSON エクスポート／インポート（機種変更・データ消失対策）
- データは端末内（IndexedDB）にのみ保存し、サーバー・認証は持たない
- GitHub Pages に GitHub Actions で自動デプロイする

## Capabilities

### New Capabilities
- `accounts`: 口座（現金・銀行・電子マネー）とクレジットカードの登録・編集・非表示、口座の初期残高および取引からの残高算出
- `transactions`: 収入・出費・振替・残高調整の入力、一覧、編集、削除
- `categories`: 収入／出費カテゴリの初期セット、追加・名前変更・非表示
- `monthly-summary`: 暦月単位の収入・出費・差額、口座別残高、カテゴリ別内訳、クレカ別利用額の表示
- `data-backup`: 全データの JSON エクスポート／インポート
- `pwa-app`: ホーム画面への追加（お金のアプリだとわかるアイコン）・オフライン動作・端末内保存・静的ホスティングでの配信

### Modified Capabilities
（なし）

## Impact

- 新規コード一式（現在リポジトリには README のみ）
- 依存追加：React, Vite, TypeScript, IndexedDB ラッパー, PWA プラグイン, テストフレームワーク
- GitHub Actions ワークフローと GitHub Pages 設定（無料プランのためリポジトリは公開。データは端末内なので公開されるのはアプリ本体のみ）
- 対象外（今回の範囲外）：クラウド同期・複数端末・複数ユーザー、予算管理、定期取引、起動時のロック、クレジットカードの引き落とし口座との連携・未払額管理
