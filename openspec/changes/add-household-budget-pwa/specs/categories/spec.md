# Spec Delta

## Purpose

収入と出費を分類するためのカテゴリを、初期セットとして用意したうえで、ユーザーが自分の生活に合わせて追加・名前変更・非表示できるようにする。

## ADDED Requirements

### Requirement: 初期カテゴリ
初回起動時、システムは次のカテゴリを SHALL 用意する。
- 出費：食費、日用品、交通費、飲み会、外食、趣味・娯楽、Amazon、衣服、その他
- 収入：給与、賞与、副業、臨時収入、その他

#### Scenario: 初回起動でカテゴリが選べる
- **WHEN** ユーザーがデータのない状態で初めて出費入力画面を開く
- **THEN** カテゴリの選択肢に「食費」から「その他」までの出費カテゴリが表示される

### Requirement: カテゴリの追加と名前変更
ユーザーは収入・出費それぞれにカテゴリを追加し、既存カテゴリの名前を SHALL 変更できる。名前は空であってはならず（MUST NOT）、同じ種別（収入／出費）の中で重複してはならない（MUST NOT）。名前を変更した場合、そのカテゴリの過去の取引も新しい名前で表示されなければならない（MUST）。

#### Scenario: カテゴリを追加する
- **WHEN** ユーザーが出費カテゴリ「サブスク」を追加する
- **THEN** 出費入力のカテゴリ選択肢に「サブスク」が表示される

#### Scenario: 重複した名前は登録できない
- **WHEN** ユーザーが既に存在する出費カテゴリ「食費」と同じ名前で出費カテゴリを追加しようとする
- **THEN** 追加は行われず、名前が重複していることが表示される

#### Scenario: 名前変更が過去の取引に反映される
- **WHEN** ユーザーが「趣味・娯楽」を「趣味」に名前変更する
- **THEN** 過去の「趣味・娯楽」の取引は一覧とカテゴリ別内訳で「趣味」と表示される

### Requirement: カテゴリの非表示
ユーザーはカテゴリを非表示に SHALL でき、再表示もできる。カテゴリの削除機能は提供しない。非表示のカテゴリは入力時の選択肢に表示してはならない（MUST NOT）が、過去の取引と月次集計ではそのカテゴリ名で表示し続けなければならない（MUST）。

#### Scenario: 使わないカテゴリを非表示にする
- **WHEN** ユーザーが過去の取引がある「Amazon」を非表示にする
- **THEN** 出費入力の選択肢から「Amazon」が消え、その月のカテゴリ別内訳には「Amazon」が引き続き表示される
