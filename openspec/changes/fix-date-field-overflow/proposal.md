# Proposal

## Why

スマホ（主に iOS Safari / ホーム画面に追加した PWA）の入力画面で、日付欄だけが右側にはみ出し、金額欄やメモ欄と左右の端がそろわない。`input` 全体には `width: 100%; min-width: 0` を指定している（`src/index.css`）が、`type="date"` はブラウザ独自の見た目（ネイティブの日付ピッカー表示）が固有の幅を持つため、この指定だけでは画面幅に収まらない。

## What Changes

- 入力画面（新規入力・取引の編集）の日付欄を、他の入力欄と同じ幅に収め、画面の左右に同じ余白を残して中央にそろえる。
- 日付欄の高さ・枠線・角丸・文字の位置を、金額欄やメモ欄と見た目がそろうようにする（日付の文字は他の欄と同じく左寄せ）。
- 日付欄の操作（タップでネイティブの日付ピッカーが開く）や保存される値は変えない。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `pwa-app`: 入力欄（日付欄を含む）が画面幅からはみ出さず、左右の余白がそろって表示されることを要件として追加する。

## Impact

- `src/index.css`: `input[type='date']` 向けのスタイルを追加する。
- `src/components/TransactionForm.tsx`: 変更なしの見込み（必要ならクラスを付ける程度）。新規入力（`NewTransactionPage`）と編集（`EditTransactionPage`）の両方がこのフォームを使うため、両画面に効く。
- テスト: jsdom ではレイアウトを計算しないため自動テストでの検証はできず、実機（スマホ）での目視確認で確かめる。
